# 手機鍵盤 PhoneKB

讓 Android 手機（Samsung A56 測試目標）變成**藍牙鍵盤 + 觸控板**。平板端不用裝任何東西，配對後就是一般藍牙鍵盤/滑鼠。

## 編譯安裝
1. 用 Android Studio 開啟 `PhoneKB` 資料夾，等 Gradle Sync（如果跳出要升級 AGP / Gradle，直接同意）。
2. A56 開開發者模式：設定 › 關於手機 › 軟體資訊 › 連點「版本號碼」7 次 → 開發人員選項 › USB 偵錯。
3. 手機接電腦 → 按 Run ▶。第一次開啟要允許「附近的裝置」權限。

## 第一次配對
1. App 裡按左下 **⚙** → 「讓平板找到我（配對）」→ 允許可被偵測 120 秒。
2. 平板：設定 › 藍牙 → 點手機的名字（例如 Galaxy A56）配對。
3. 頂端細線變**綠色** = 已連線。之後打開 App 會自動重連上一台。

> 一定要從**平板端**發起配對。如果手機之前已經跟平板配對過（當一般手機），先在兩邊都「忘記裝置」再重配，否則平板不會把它當鍵盤。

## 注音 / 英數 兩種模式
按鍵位置相同，只換顯示：
- **注音模式**：按鍵大字是注音，左上角小字是英文/數字。
- **英數模式**：按鍵大字是英文字母和數字，左上角小字是 Shift 符號。

【中/英】鍵（顯示目前模式，注音＝橘色、英數＝綠色）：
- **點一下**：手機換模式，同時送 Ctrl+Space，讓平板的輸入法一起切。
- **長按**：只換手機顯示、不送鍵。兩邊對不上時（手機顯示英數、平板卻打出注音）用來校正。

iPad 設定：
1. 設定 › 一般 › 鍵盤 › 鍵盤：只留 **English** 和 **注音** 兩個（多了 Ctrl+Space 會切到第三種）。
2. 連上後：設定 › 一般 › 鍵盤 › 實體鍵盤 › 繁體中文-注音 → 選「標準」排列。
3. 注音模式空白鍵 = 一聲，用方向鍵 / Enter 選字。

原理：HID 只能送「哪個鍵被按」，組字由平板的輸入法負責，所以手機只是換顯示，送出的 keycode 兩種模式都一樣。

## 操作
| 鍵盤模式 | |
|---|---|
| 按住 Shift + 字母 | 大寫 / 符號（支援多指） |
| 單點 Shift / Ctrl / ⌥ / ⌘ | 黏住到下一個鍵（變深藍色），再點一次取消 |
| 長按任何鍵 | 由平板端連發（跟實體鍵盤一樣） |
| 中/英 | 點：手機＋平板一起切換注音/英數；長按：只切手機 |
| 🖱 | 切到觸控板 |
| ⚙ | 連線 / 設定 |

| 觸控板模式 | |
|---|---|
| 單指滑 | 移動游標（有加速度） |
| 單指輕點 | 左鍵 |
| 雙指輕點 | 右鍵 |
| 雙指滑 | 捲動（上下左右） |
| 輕點後馬上按住再拖 | 拖曳 |
| 底部 左鍵/右鍵 | 可按住；⌨ 切回鍵盤 |

靈敏度、捲動方向在 ⚙ 裡調。模式會記住，下次打開維持上次的。

## 檔案
- `Hid.kt` — HID Report Descriptor（Report 1 鍵盤 8B、Report 2 滑鼠 5B）與 keycode
- `HidController.kt` — `BluetoothHidDevice` 註冊、連線、送 report
- `KeyboardLayout.kt` — 鍵盤排列（每列 15 單位寬）、注音對照、模式定義
- `KeyboardView.kt` — 全螢幕鍵盤繪製 + 多指觸控 + 修飾鍵邏輯 + 注音/英數切換
- `TouchpadView.kt` — 觸控板手勢
- `MainActivity.kt` — 權限、全螢幕、設定視窗

## 常見問題
- **⚙ 顯示「註冊 HID 失敗」**：同一時間只能有一個 App 當 HID 裝置。關掉其他鍵盤滑鼠 App（例如 Bluke），或關掉再打開手機藍牙。
- **平板的藍牙清單找不到手機**：確認 App 開著、剛按過「讓平板找到我」；兩邊都忘記裝置後重來。
- **游標太慢/太快**：⚙ 調靈敏度。捲動方向相反就勾「反轉捲動方向」。
